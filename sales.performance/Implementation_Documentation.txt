# ARROWSTACK DATA ANALYTICS INTERNSHIP

# IMPLEMENTATION DOCUMENTATION

## 1. Project Title

Sales Performance Dashboard Using Microsoft Power BI

## 2. Problem Statement

Businesses need an accessible way to analyze e-commerce sales, understand product and regional performance, and monitor marketing lead conversion. This project uses Power BI to organize relevant datasets into interactive reports.

## 3. Requirements

* Import and clean the relevant datasets.
* Establish appropriate data relationships.
* Create DAX measures for key performance indicators.
* Build sales and marketing funnel visualizations.
* Add interactive slicers.
* Validate calculations and report behavior.
* Document the workflow and prepare a reproducible submission package.

## 4. Implementation

The project uses the Olist Brazilian E-Commerce Public Dataset and Olist Marketing Funnel Dataset.

Power Query Editor is used to inspect data quality, review missing values, and check data types.

Power BI data modeling is used to establish relationships between relevant sales tables and between marketing qualified leads and closed deals.

DAX measures are used to calculate revenue, average order value, total orders, total leads, converted leads, and marketing conversion rate.

## 5. Testing and Validation

The validation process includes:

* Selected data quality checks.
* Duplicate key checks.
* Data type checks.
* Relationship checks.
* KPI card checks.
* Chart checks.
* Slicer interaction checks.

Detailed results are recorded in Validation_Log.txt. Screenshots should be added as supporting evidence.

## 6. Limitations

The marketing funnel dataset does not establish a verified connection between marketing leads and e-commerce orders. Therefore, marketing lead conversion is reported separately from sales performance.

Total Revenue is calculated using item prices and excludes freight charges.

## 7. Reproducibility

The final project package should include the Power BI PBIX file, README, validation log, supporting screenshots, and any required source datasets or links.

A mentor should be able to open the PBIX file, review the data model, inspect the measures, and interact with the report.
