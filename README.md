## 📊 Project Overview
This repository contains the complete work for Arrowstack Data Analytics Internship, focusing on building end-to-end dashboards for business performance monitoring.

The project consists of two major dashboards:
1.  **Sales Performance Dashboard**
2.  **Operation SLA / Customer Support Dashboard**

---

### 🔹 Task 1: Sales Performance Dashboard

**Objective:** To analyze Olist e-commerce sales data and build an interactive dashboard to track sales performance.

**Dataset:** Olist Brazilian E-Commerce Dataset (9 CSV files)
- `olist_orders`, `olist_order_items`, `olist_products`, `olist_customers`, `olist_order_payments`, `olist_order_reviews`, `olist_sellers`, `olist_geolocation`, `olist_product_category_name_translation`

**Tools Used:**
- Power BI Desktop (`arrowstackproject1.pbix`)
- Power Query, DAX

**Key KPIs & Visuals:**
- Total Sales, Total Orders, AOV (Average Order Value)
- Sales by Product Category, Payment Type, Customer State
- Monthly Sales Trend, Revenue by Seller
- Order Status Analysis, Customer Review Score Impact

**Key Insights:**
- Identified top-performing product categories
- Analyzed payment method preference and its correlation with sales
- Tracked monthly growth and seasonal trends

**Folder:** `/sales.performance`

---

### 🔹 Task 2: Operation SLA - Customer Support Ticket Dashboard

**Objective:** To monitor customer support operations and SLA (Service Level Agreement) compliance.

**Dataset:** `customer_support_ticket.xlsx`

**Tools Used:**
- Power BI Desktop (`operation_sla.pbix`)
- Excel, Power Query

**Key KPIs & Visuals:**
- Total Tickets, Open vs Closed vs Pending Tickets
- SLA Compliance % (Met vs Breached)
- Average Resolution Time, Average First Response Time
- Tickets by Priority, Category, Support Agent, Channel
- SLA Breach Analysis by Issue Type

**Key Insights:**
- Identified major reasons for SLA breaches
- Analyzed agent performance and workload distribution
- Provided recommendations to improve response time and customer satisfaction

**Folder:** `/operation_sla`
